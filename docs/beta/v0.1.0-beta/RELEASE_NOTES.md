## Install (DMG First)
- Download DMG from the draft release assets.
- Verify checksums with `SHA256SUMS.txt`.
- Mount DMG and drag `FlowState.app` to `/Applications`.

## Gatekeeper Workaround (Unsigned)
- Right-click `FlowState.app` in Finder and choose Open.
- Confirm Open in macOS warning dialog.

## What Is Included
- Desktop app packaging pipeline with deterministic artifact naming and manifest integrity checks.
- Beta guide, privacy notice, feedback channel definitions, and operations playbook.

## Known Limits
- Unsigned build requires first-launch Finder Open flow.
- Final cohort matrix and non-technical first-run rubric completion tracked at launch gate.

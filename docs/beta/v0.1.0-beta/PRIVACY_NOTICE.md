## Core Privacy Commitments
- FlowState stores settings, tokens, and memory locally on this Mac under `~/Library/Application Support/FlowState/`.
- FlowState does not send telemetry or usage analytics by default.
- Optional support log sharing is opt-in and can be revoked in Settings.

## Consent Rules
- Default for log sharing is Off.
- Consent requires an explicit control and is not implied by onboarding continuation.
- Before sending logs, users can preview included/excluded data categories.
